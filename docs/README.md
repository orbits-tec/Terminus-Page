# Terminus

Um emulador de terminal para macOS baseado em [SwiftTerm](https://github.com/migueldeicaza/SwiftTerm).

## Requisitos

- macOS 15 (Sequoia) ou superior

## Atalhos de teclado

| Atalho | Descrição            |
|:------:|----------------------|
| `⌘D`   | Split vertical       |
| `⌘⇧D`  | Split horizontal     |
| `⌘⌃W`  | Fecha o painel ativo |
