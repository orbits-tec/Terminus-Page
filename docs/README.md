# Terminus

Um emulador de terminal para macOS baseado em [SwiftTerm](https://github.com/migueldeicaza/SwiftTerm).

## Requisitos

- macOS 15 (Sequoia) ou superior

## Atalhos de teclado

| Atalho                   | Descrição            |
|:------------------------:|----------------------|
| `Command + D`            | Split vertical       |
| `Command + Shift + D`    | Split horizontal     |
| `Command + Control + W`  | Fecha o painel ativo |
